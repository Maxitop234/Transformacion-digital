# T-0NN · Título de la tarea

| Campo | Valor |
| --- | --- |
| Fase | N · Nombre de la fase |
| Dimensión de la pauta | 1 a 5, o «—» |
| Depende de | T-0XX, o «Ninguna» |
| Desbloquea | T-0YY, o «Ninguna» |
| Componentes | `apps/web`, `infra/aws`, … |
| Estado | Ver [índice](../README.md) |

## Objetivo

Una o dos frases: qué queda funcionando al terminar y para quién.

## Referencias

Leer antes de empezar:

- Secciones concretas de `docs/` (por ejemplo `BUSINESS_RULES.md RN-04`).
- ADR que condicionan la solución.
- [`AGENTS.md`](../../AGENTS.md): convenciones y límites

## Alcance

- Entregables concretos, uno por línea.

## Fuera de alcance

- Lo que podría confundirse con parte de esta tarea y pertenece a otra.

## Criterios de aceptación

- [ ] Condiciones verificables ejecutando un test, un comando o un recorrido.
- [ ] La documentación afectada quedó actualizada y el estado se cambió en el índice.

## Notas

_Decisiones tomadas, comandos útiles, pendientes y bloqueos._
